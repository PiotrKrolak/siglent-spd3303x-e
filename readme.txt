# Siglent SPD3303X-E LabVIEW Controller
This repository contains a LabVIEW application built from scratch to control the Siglent SPD3303X-E Triple Output DC Power Supply.
The application features a custom-designed Front Panel that accurately mimics the appearance of the original physical device for intuitive operation. It provides full SCPI-based control over all channels (voltage/current setting and reading).
